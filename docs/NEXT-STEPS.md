## ⚠️ Диагностика краша на старте (в процессе)

Приложение падает сразу при открытии, ещё до появления UI — крашится настолько
рано, что не срабатывает даже `CrashLogger.kt` (файл в Загрузки не появляется).
Это указывает на что-то раньше `MainActivity.onCreate()` — главный подозреваемый —
`network_security_config.xml` (Android применяет его очень рано в жизненном цикле
процесса, до пользовательского кода).

**Текущий шаг**: `android:networkSecurityConfig` временно убран из
`AndroidManifest.xml` (закомментирован, не удалён) — диагностическая сборка без
него. Если приложение с этой сборкой откроется — причина подтверждена, дальше
разбираемся с самим XML/сертификатами. Если всё равно упадёт — причина в чём-то
другом, возвращаем атрибут на место и ищем дальше (скорее всего, вернёмся
к беспроводной отладке через adb).

## Обязательно перед следующей сборкой: сертификат Минцифры

GigaChat API (P1) требует доверенный корневой сертификат НУЦ Минцифры — без него
TLS-соединение обрывается. Сами файлы сертификатов **не входят в архив** (см.
`docs/DECISIONS.md`) — их нужно скачать и положить в проект самостоятельно, иначе
сборка упадёт с ошибкой "resource not found" на `network_security_config.xml`.

В корне проекта (`~/work/ContentApp` в Termux):
```
mkdir -p app/src/main/res/raw
curl -o app/src/main/res/raw/russian_trusted_root_ca.crt https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
curl -o app/src/main/res/raw/russian_trusted_sub_ca.crt https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt
```
Дальше — обычные `git add -A && git commit && git push` и `gh workflow run build-apk.yml`.
Эти URL — официальные ссылки Минцифры на сертификаты, если недоступны — поискать
актуальные на сайте `gosuslugi.ru` (раздел про установку сертификата НУЦ Минцифры).

## 1. Получить ключ GigaChat

Один ключ на оба провайдера — и P1, и P4 теперь идут через GigaChat:
https://developers.sber.ru/studio → создать проект → "API GigaChat" → скопировать
готовый ключ авторизации (Base64) → вписать в `local.properties` как
`GIGACHAT_AUTH_KEY`.

Без ключа сборка пройдёт, но оба сервиса будут возвращать понятную ошибку вместо
результата.

Промежуточные попытки для P4 (не пригодились, для истории — см. `DECISIONS.md`):
Kandinsky/FusionBrain (`fusionbrain.ai` оказался практически недоступен на
практике), затем YandexART (требует привязать банковскую карту к Yandex Cloud
даже для бесплатного лимита — не подходило под требование "без карты"). Обе
реализации удалены из проекта, есть в истории git при необходимости.
