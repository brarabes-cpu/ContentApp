# START HERE — ContentApp

**Версия: v1** — упрощённая версия: без регистрации, без оплаты, только
бесплатная модель Gemini. Полная версия v0 (регистрация, оплата — Google Play
Billing + ЮKassa, две модели ИИ по уровню качества) зафиксирована отдельным
архивом `ContentApp_v0.zip` для истории и возможного возврата.

Если контекст разговора потерян (новый чат, новая сессия) — читать в таком порядке:
**этот файл → `docs/NEXT-STEPS.md` → `docs/DECISIONS.md` → `docs/SPEC.md`.**

## Что это

Android-приложение (Kotlin + Jetpack Compose): пользователь вводит короткое
желание, приложение через ИИ разворачивает его в детализированный промт и
генерирует изображение. Без монетизации.

## Как продолжать работу в чате

В проекте принята единая ID-нотация (см. `SPEC.md`): экраны `S1`/`S2`, элементы
`S1.B2`, процедуры `P1`, `P4`… Можно сразу писать "доработай S2.B1" — не нужно
объяснять контекст заново.
